VAIHE 1 - "Aina paalla" on tehtava todeksi (Ubuntu + Windows)
--------------------------------------------------------------
Tama EI ole vielä totta: WSL kaatui, Tailscale katosi ja openssh-server jai
puolitiehen kun levy tayttyi. WSL2-vieras ei myoskaan kaynnisty Windowsin
mukana.

Ubuntu-shellissa:

    sudo tee /etc/wsl.conf <<'WSLEOF'
    [boot]
    systemd=true
    WSLEOF

    sudo dpkg --configure openssh-server
    sudo dpkg --audit

Windows PowerShellissa:

    wsl --shutdown

Sitten takaisin Ubuntuun (systemd on nyt kaytossa):

    sudo systemctl enable --now tailscaled
    sudo systemctl enable --now ssh
    systemctl is-enabled tailscaled ssh

Windowsin ajastettu tehtava kaynnistykseen (Task Scheduler, "Run whether
user is logged on or not", trigger: At startup):

    Ohjelma:    wsl.exe
    Argumentit: -d Ubuntu -u root /bin/true

Windowsin virransaasto: ei lepotilaa. Nukkuva kone ei palvele.


VAIHE 2 - HTTPS paalle tailnetiin (selaimessa)
-----------------------------------------------
PAIKANNUS EI TOIMI ILMAN TATA. navigator.geolocation vaatii turvallisen
kontekstin: http://kone:8000 on estetty, localhost on ainoa poikkeus.

Tailscalen hallintapaneeli -> DNS:
  - MagicDNS                      paalle
  - HTTPS Certificates            paalle

Tarkista Ubuntulla etta nimi on tiedossa:

    tailscale status --json | grep -i dnsname

VAIHE 5 - Palvelin (Ubuntu)
----------------------------
tailscale serve paattaa HTTPS:n oikealla sertifikaatilla ja nakyy VAIN
tailnetissa - ei julkiseen verkkoon.

POLUN ON OLTAVA ABSOLUUTTINEN. Suhteellinen "docs" tulkitaan
verkko-osoitteeksi, ei hakemistoksi:

    error: non-localhost target "http://docs" must include a scheme

    tailscale serve --bg /home/tsaulial/saaristorantautuminen-0826/saaristorantautuminen/docs

    tailscale serve status

Osoite on muotoa  https://<kone>.<tailnet>.ts.net

Asetus sailyy uudelleenkaynnistysten yli (--bg kirjoittaa sen tailscaled:n
tilaan), joten tata ei tarvitse toistaa.

Lopettaminen jos tarvitsee:

    tailscale serve --https=443 off


VAIHE 6 - Todentaminen
-----------------------
Toiselta laitteelta tailnetissa:

  1. https://<kone>.ts.net avautuu ja kartalla nakyy SEKA Saaristomeri
     ETTA Paijanne
  2. paikannuspainike oikeassa ylalaidassa toimii (vaatii vaiheen 2)
  3. asetussivun rantapituus on tuhansia kilometreja, ei 700 km
  4. Windows uudelleen kayntiin -> osoite vastaa ilman kasin kaynnistysta

Selaimen valimuisti on tassa projektissa johtanut harhaan kolmesti. Jos
sivu nayttaa vanhalta rakentamisen jalkeen, tarkista kovalla latauksella
(cmd/ctrl + shift + R) ennen kuin epailet buildia.
